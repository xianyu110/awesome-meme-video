### Which photo works best?

Use **one clear photo of you** from the chest up, looking into the camera. The portrait is a close-up of your eyes, so the eyes in your photo matter most.

## What can go wrong, and the fix

- **The eyes look like someone else's.** Use a sharp, front-facing photo with open eyes, and run it again: each run is a little different.
- **Something else is in color.** The prompt keeps only the sweater (and your eye color) in color. A lipstick or a necklace in color can slip through now and then: run it again.
- **The hands look odd.** Hands under big sleeves are hard for any AI. The prompt asks for no distorted hands; if a finger looks wrong, run it again.
- **The face is fully hidden.** The sleeves should stop under the nose. If a result hides more, run it again.

If a run fails, the credits come back.
